Run a prompt and vibe coding review

Goal​

Review a prompt (or pack) to ensure it meets style, safety, and evaluation requirements.

Steps​

  1. Collect the prompt, intended routes/models, and recent outputs.
  2. Check style cues: tone, concision, formatting, taboo words.
  3. Verify safety and refusal guidance; confirm tool allowlists.
  4. Ensure evaluation probes exist for groundedness, safety, and latency.
  5. Record changes and decisions in a prompt changelog.

Verification​

  • Prompt includes explicit role, scope, style cues, and refusal guidance.
  • Tool usage is explicit and matches gateway/MCP policies.
  • Evaluation probes run cleanly across providers.

Rollback​

  • Revert to the previous prompt version in source control.
  • Disable new prompt in gateway routes until fixes land.
